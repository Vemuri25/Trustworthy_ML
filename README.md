# Trustworthy ML Monitor

An end-to-end machine learning project investigating data quality,
distribution drift, model performance, and prediction reliability.

## Planned features
- Reproducible data preprocessing
- Income classification baseline
- Model evaluation and error analysis
- Data drift monitoring
- Prediction API and dashboard
- Automated tests

## Dataset
UCI Adult Census Income:
https://archive.ics.uci.edu/dataset/2/adult

## Status
Environment setup and data inspection.

## Responsible use
This project is for educational research. It is not intended for
employment, credit, or other consequential individual decisions.
